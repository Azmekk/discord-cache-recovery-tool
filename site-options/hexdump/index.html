How it works

No magic, and nothing you couldn't check yourself in the source.

  1. Reads Discord's local cache

    It finds each Discord install on your computer and opens its HTTP cache folder. It reads just the start of each file to see what it is, so thousands of files take seconds.

  2. Pairs each file with its link and date

    The cache index stores the address every file was downloaded from and when. That's where the original file name and the posted date come from.

  3. Sorts it into a gallery

    The link tells it whether a file is an attachment, a GIF, an emoji or an avatar. Duplicate sizes get grouped, and you browse, search and export.

What it can't do. It only recovers what's still in the cache. Discord removes old entries as the cache fills up, and clearing the cache deletes everything. It also can't tell which server or favorites tab something came from, though attachments do include the channel ID.

Questions people ask

Can this get my Discord account banned?

It never logs in, never uses your account or token, never talks to Discord's servers and never changes the Discord app. It only reads files that are already on your computer, so there's nothing for Discord to see.

Is it a virus? My antivirus or SmartScreen warned me.

The warning appears because the builds aren't code-signed, not because anything harmful was found. The app is open source and built from the public code on GitHub, so you or anyone else can check exactly what it does.

Why can't I find my GIF?

It can only recover what's still in the cache. Discord deletes old entries as the cache fills up, and clearing the cache removes everything. If you haven't seen the GIF in Discord for a long time, it may already be gone. Try searching by part of its link, or filter by GIFs and sort by date.

Can it tell me which server something came from?

No. The cache doesn't record servers or which favorites tab a GIF was in. Attachments do include the channel ID, and you can give channels your own names to search by them.

Does Discord need to be closed?

Usually not. On Windows, if the app says the cache is locked, quit Discord fully from the tray icon (right-click, then Quit Discord) and scan again.

My Mac says the app is "damaged". What now?

That's how macOS treats apps that aren't signed. Open Terminal and run xattr -cr "/Applications/Discord Cache Recovery.app" once, then open the app normally.

C

How it works

No magic and no undelete. Discord keeps a local copy of what it shows you, and the app reads that copy.

  1. Open the cache

    It finds Discord's local HTTP cache for each install on your computer, or a folder you point it at.

  2. Read the tags

    The cache index stores the link and date for every file. The app pairs each file with its entry.

  3. Sort onto belts

    Files are sorted by kind (attachments, GIFs, emojis and so on) into a gallery you can search.

If your file isn't there

  • It can only recover what's still in the cache. Discord removes old entries as the cache fills up, and clearing the cache deletes everything.
  • It can't tell which server or favorite-GIF tab something came from. Attachments do include the channel ID.

Your computer may warn you once

The builds aren't code-signed, so Windows and macOS don't recognize the publisher. That's the whole reason for the warning.

Windows: on the SmartScreen prompt, click More info, then Run anyway.

macOS: if it says the app is damaged, open Terminal and run this once: xattr -cr "/Applications/Discord Cache Recovery.app"

E

Questions

Can this get my Discord account banned?

It never logs in, never uses your account or token and never talks to Discord's servers. It reads files that are already on your disk, the same way a file browser would. Discord has nothing to detect.

Is it a virus? Windows is warning me.

The warning appears because the builds aren't code-signed. The full source code is public on GitHub, and the release builds are made from it automatically. Click More info, then Run anyway.

Why can't I find my GIF?

It's only there if it's still in the cache. Discord removes old entries as the cache fills up, and clearing the cache deletes everything. Try searching by part of the link (for example "tenor"), and check every Discord install in the filters.

Can it tell which server something came from?

Not directly. The cache doesn't record servers or favorite-GIF tabs. Attachments do include the channel ID, and you can give channels your own names to search by them.

Does Discord need to be closed?

Usually not. On Windows, if the app says the cache is locked, quit Discord fully from the tray icon (right-click, then Quit Discord) and scan again.

My Mac says the app is damaged.

That's macOS refusing unsigned apps. Open Terminal and run xattr -cr "/Applications/Discord Cache Recovery.app" once, then open the app normally.

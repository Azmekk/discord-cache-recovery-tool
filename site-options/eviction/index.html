How it works

No magic and no internet. Discord already stores this media on your disk so it can load faster.

  1. It finds Discord's cache

    Discord keeps a local HTTP cache of the media it shows you. The app finds it for each Discord install on your computer, or a folder you point it at.

  2. It pairs each file with its link and date

    The cache index records where every file came from and when. The app reads that without opening whole files, so thousands are scanned in seconds.

  3. It sorts everything by kind

    Attachments, GIFs, emojis, stickers, avatars and embeds land in their own groups, ready to search, preview and export.

What it can't do

It can only recover what's still in the cache. Discord removes the oldest entries as the cache fills up, and clearing the cache deletes everything, so the sooner you look, the better. It also can't tell which server or favorite-GIF tab something came from, though attachments do include the channel ID.

Windows says "Windows protected your PC"

The builds aren't code-signed, so SmartScreen doesn't recognise them yet. Click More info, then Run anyway.

macOS says the app is damaged

It isn't. macOS blocks unsigned apps this way. Run this once in Terminal:

xattr -cr "/Applications/Discord Cache Recovery.app"

The app says the cache is locked

On Windows, quit Discord fully: right-click its tray icon, choose Quit Discord, then scan again.

Questions people ask first

Can this get my Discord account banned?

It never logs in, never uses your account or token, and never talks to Discord's servers. It reads files that are already on your disk, the way a file browser would, so there's nothing on Discord's side for it to touch.

Is it a virus? Windows warned me.

The warning appears because the builds aren't code-signed, not because anything harmful was found. The full source is public on GitHub under the MIT license. If you trust it, click More info, then Run anyway.

Why can't I find my GIF?

Discord only keeps a limited amount of media and removes the oldest as its cache fills up. If the GIF was evicted, or the cache was cleared, it's no longer on your computer. Try filtering to GIFs and searching part of its link, like "tenor". If you use Discord on another computer, scan that one too.

Can it tell me which server something came from?

Not directly. The cache doesn't record servers or favorite-GIF tabs. Attachments do include the channel ID, and you can give channels your own names so they're easy to search later.

Do I need to close Discord?

Usually not. On Windows the cache can be locked while Discord is running. If the app says so, quit Discord from its tray icon (Quit Discord) and scan again.

macOS says the app is damaged. What now?

That's macOS blocking an unsigned app, not real damage. Run xattr -cr "/Applications/Discord Cache Recovery.app" once in Terminal, then open the app again.
